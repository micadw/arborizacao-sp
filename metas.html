Meta 85 do PlanClima por distrito

A meta pede +1 ponto percentual de cobertura vegetal em cada distrito até 2028, sobre o mapeamento de 2017. A barra mostra a base de cada distrito e o traço, o alvo. O avanço só poderá ser medido quando um novo mapeamento for publicado.

Código 
dd = distritos.features.map(f => ({nome: f.properties.nm_distrito_municipal, base: f.properties.pct_cobertura_vegetal, alvo: f.properties.pct_cobertura_vegetal + 1}))
viewof ordem = Inputs.radio(new Map([["Menor cobertura primeiro", "asc"], ["Maior cobertura primeiro", "desc"]]), {value: "asc", label: "Ordem"})
viewof n = Inputs.range([10, 96], {value: 30, step: 1, label: "Distritos exibidos"})
Código 
Plot.plot({
  marginLeft: 170, height: n * 18 + 40, width: 760,
  style: {background: "transparent", color: "currentColor"},
  x: {label: "Cobertura vegetal (% da área)", grid: true},
  y: {label: null, domain: d3.sort(dd, d => ordem === "asc" ? d.base : -d.base).slice(0, n).map(d => d.nome)},
  marks: [
    Plot.barX(dd, {y: "nome", x: "base", fill: "base", tip: true, title: d => `${d.nome}\nbase 2017: ${fmt(d.base, 1)}%\nalvo 2028: ${fmt(d.alvo, 1)}%`}),
    Plot.tickX(dd, {y: "nome", x: "alvo", stroke: "#f9a825", strokeWidth: 2}),

})
